# Utkarsh Kushwaha — Portfolio

> Gen AI & Full-Stack Consultant at Deloitte USI

An interactive, high-performance portfolio showcasing enterprise AI systems, full-stack architecture, and interactive 3D WebGL experiences.

## 🚀 Tech Stack

- **Frontend**: Vanilla JS (ES Modules), HTML5, Tailwind CSS
- **Creative / 3D**: Three.js, GSAP (ScrollTrigger & ScrollTo), Lenis Smooth Scroll
- **Tooling & Build**: Vite, PostCSS, Autoprefixer

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
